TEKNOFEST Combat UAV Project
A simulation environment I created for testing autonomous attack algorithms.
Kamikaze_denem.zip contains a visual demonstration of the kamikaze mission algorithm test.

The system can be used on Ubuntu 20.04 with the help of the install helper.
